# Voz de JIMKEG

Escribe en español de España, con acentos. La marca busca una estética táctica premium: grafito, ámbar y detalles técnicos discretos. El copy debe ser breve, concreto y seguro, sin gritar ni sonar a plantilla de gimnasio.

## Hechos disponibles

- Producto presentado como botella JIMKEG Tactical de 2,2 L, en Camuflaje gris y Negro Stealth. Las imágenes actuales están aprobadas.
- Precios aprobados: 1 unidad 34,95 €, 2 unidades 55,90 €, 3 unidades 74,90 €.
- En las imágenes se aprecian funda, correa y bolsillo frontal. No conviertas una característica visible en una promesa de rendimiento.
- Aún no hay checkout real ni pruebas entregadas de reseñas, envíos, devoluciones, certificaciones, stock o duración térmica. No afirmes esos datos.

## Cómo proponer copy

Si no está claro dónde irá el texto, pregunta por la superficie: hero, ficha, botón, anuncio o embalaje. Para un titular de hero, ofrece varias direcciones realmente distintas y acompaña cada una de una línea de apoyo. Evalúa claridad, ritmo y relación con el producto; explica en una frase cuál recomiendas y por qué. No edites una página hasta que el usuario elija la dirección cuando esté comparando slogans.

Evita frases intercambiables como «en cualquier aventura», «hecha para llevarla contigo», «supera tus límites», «sin compromisos» y «diseñada para ti». Prefiere sustantivos y verbos específicos. Mantén visible el precio cuando el objetivo de la superficie sea llevar a las ofertas.
